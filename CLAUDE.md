# CLAUDE.md

## Правила дизайна

### Типографика
- Два шрифта. LT Amber Condensed (--font-display) только капсом: Medium для заголовков, Regular для подписей и меток (12–18px, трекинг 4–8%, --tracking-label). Pliant (--font-body) для всего остального, обычный регистр: Light основной, Regular только для смысловых выделений.
- Запрещено: LT Amber строчными, длинный русский текст капсом, третий шрифт, чистые #000 и #fff, случайные серые, хаос размеров.
- Размеры только через готовые токены. Новые размеры не вводить. Шкала по брендбуку: H1 64–88px, H2 40–56px, H3 24–34px, Label 12–18px, Body 16–18px, Caption 12–14px. Подзаголовок страниц 15px (--text-subtitle) допустимое исключение.
- Pliant: межбуквенный −1…−3%, межстрочный 1.3–1.5. Выравнивание по левому краю, центровка только в общей карточке товара.
- Вторичный текст --color-text-secondary (Warm Black 68%).

### Заголовки секций
- H1 страницы всегда LT Amber Medium, капс.
- Главная и витринные страницы (о галерее, услуги, профессионалам), где секция открывает новую тему: H2 (LT Amber Medium, капс, 40–56px).
- Внутренние страницы (бренд, товар, интерьеры), где секции раскрывают один предмет: подпись секции с линией (LT Amber Regular, капс, 14px). В коде всегда настоящий h2. Использовать общий компонент подписи секции.
- Проверка: новая тема со своим текстом или большим фото = H2; часть того же предмета (товары бренда, документы, авторы) = подпись.

### Цвета
- Snow Ivory #F2F0EB фон, Warm Black #2C2929 текст, Olive Graphite #4A412A материальный акцент, Cream Ivory #D7D2CB, Champagne #84754E только линии и мелкие детали.
- Не более одной цветной полосы на страницу (например «Авторы» на странице бренда). Два тёмных блока подряд не ставить. Только цвета-токены.

### Элементы управления
- Кнопка с рамкой: главное действие, не больше одной на экран, использовать существующий компонент. Новых стилей кнопок не создавать.
- Текстовая ссылка (LT Amber Regular, капс, 14px, со стрелкой →): второстепенные переходы, в строке заголовка секции справа.
- Круглые стрелки 40px (тонкие шевроны, один общий компонент): только «вперёд/назад» у слайдеров.
- Квадратные образцы цвета: данные, а не кнопки.
- Действия, появляющиеся при наведении (кнопки на карточках), на устройствах без наведения (hover: none) должны быть всегда видны.

### Слайдеры и карточки
- Один общий компонент слайдера. Стрелки показываются только если элементов больше колонок (подборка 3, интерьеры и каталоги 4). Не больше двух слайдеров на странице. Анимация 400–500ms ease, при prefers-reduced-motion без анимации. На мобильном горизонтальный ряд со свайпом (scroll-snap).
- Карточка товара: один общий компонент на всём сайте (образцы цвета, категория, название LT Amber Medium капс --text-model-title, бренд; на странице бренда бренд скрыт). Фото в сетках 4:3. Нельзя копировать разметку карточки.
- В карточки товаров не ставить фото с логотипом бренда внутри кадра.

### Данные и содержимое
- Блок показывается только когда есть данные. Пустых заголовков и серых заглушек «ID» нет. Демо-данные в отдельном файле с флагом demo: true, подключаются через VITE_DEMO_DATA. Имён и ФИО не выдумывать (в демо буквально «ФИО»).
- На сайте нет цен и наличия, их не придумывать. Bitrix и 1С нигде не упоминать. Запрещённые слова проверяет npm run check:content.
- Параметры адреса: комната ?room=, бренд ?brand=, поиск ?q=. Поиск сбрасывает бренд и комнату. Действующее ограничение всегда видно (крошки, заголовок, ссылка «Весь каталог ID Gallery»).

### Процесс
- Меняй только то, что просят, другие страницы не трогай. Токены вместо жёстких значений.
- После правок: tsc, vite build, npm run check:content, npm run check:images без новых ошибок.
- В конце ответа: список изменённых файлов и список неиспользуемых стилей или файлов, которые остались.
