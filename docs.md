13. Техническое задание: Оптимизация сайта для индексации AI-моделями и генеративными поисковиками (GEO/AIO)
Цель: Обеспечить беспрепятственное сканирование, правильную интерпретацию и приоритетное ранжирование контента сайта большими языковыми моделями (LLM) и AI-поисковиками с акцентом на локальные (геозависимые) запросы пользователей.
13.1. Настройка доступа для AI-краулеров (Crawling & Indexing)
robots.txt: Явно разрешить (не блокировать) сканирование для основных AI-ботов.
Список ключевых ботов для проверки: PerplexityBot, OAI-SearchBot (SearchGPT), ChatGPT-User, Google-Extended (Gemini), Anthropic-ai, ClaudeBot, Applebot-Extended.
Рендеринг (критично для SPA): AI-боты плохо (или вообще не) исполняют сложный JavaScript. Если сайт написан на React/Vue/Angular, обязательно использование Server-Side Rendering (SSR) через Next.js/Nuxt.js или настройка Dynamic Rendering (например, через Prerender.io), чтобы боты получали чистый HTML-код.
XML Sitemap: Должна автоматически обновляться и содержать все страницы локаций, шоурумов и региональных предложений.
2. Геолокационная микроразметка (Structured Data)
Внедрить разметку LocalBusiness (или более узкие форматы, например, FurnitureStore, HomeGoodsStore). Разметка должна присутствовать на страницах контактов и страницах конкретных шоурумов.
Обязательные поля для GEO:
name, description, url, image.
address (с детальной разбивкой: streetAddress, addressLocality (город), postalCode, addressCountry).
geo (точные координаты: latitude и longitude).
areaServed (территория обслуживания — критично важно, если бренд находится в одном городе, но работает по всему региону или стране).
telephone, openingHoursSpecification.
Формат: Разметку внедрять строго в формате JSON-LD (в теге <head>).
3. Семантическая чистота HTML (Machine-Readable Structure)
Теги структуры: Использовать корректные HTML5-теги: <header>, <main>, <section>, <article>, <aside>, <footer>.
Тег <address>: Всю контактную информацию (физические адреса шоурумов, телефоны) на страницах оборачивать в тег <address>.
Иерархия заголовков (H1-H6): Строго соблюдать логику. Например, H1 — название регионального раздела («Эксклюзивная мебель в [Город]»), H2 — адреса шоурумов, H3 — детали. Не использовать заголовки просто для изменения размера шрифта.
4. Контентная адаптация под GEO-сигналы (Техническая часть)
Футер (Подвал сайта): Вывести единый блок с ключевой GEO-информацией (Адрес главного шоурума, Страна, Город) сквозным блоком на всех страницах.
Альтернативные тексты (Alt) для изображений: Разработчики должны предусмотреть обязательное поле alt в CMS для всех фотографий интерьеров и шоурумов. Шаблон генерации Alt должен включать локацию (например: "Интерьер шоурума [Бренд] в [Город, Страна]").
Интеграция с картами: На страницах контактов встроить Google Maps / Яндекс.Карты через API, добавив рядом машиночитаемый текстовый эквивалент адреса (так как AI не «видит» интерактивную карту).
5. Производительность (Performance & Core Web Vitals)
Время ответа сервера (TTFB): Менее 300 мс.
Скорость загрузки HTML: Максимально быстрая отдача текстового документа до загрузки тяжелых скриптов и видео.
Чистота DOM-дерева: Избегать чрезмерной вложенности <div>, которая усложняет парсинг текста нейросетями.
