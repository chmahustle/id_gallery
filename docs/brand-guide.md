# ID Gallery — Brand Guide (выжимка для веба)

Источник: ID GALLERY — Logo Rules Brand Guide. Этот файл — рабочая выжимка для разработки сайта. Полные правила логотипа и печати — в утверждённом брендбуке.

## Палитра

| Имя | HEX | RGB | Роль на сайте |
| --- | --- | --- | --- |
| Snow Ivory | `#F2F0EB` | `242, 240, 235` | Основной фон страниц |
| Warm Black | `#2C2929` | `44, 41, 41` | Текст, навигация, тёмные фоны |
| Olive Graphite | `#4A412A` | `74, 65, 42` | Кнопки, спокойный акцент |
| Cream Ivory | `#D7D2CB` | `215, 210, 203` | Вторичный фон, разделители, заглушки |
| Champagne | `#84754E` | `132, 117, 78` | Только мелкие детали (линии, иконки, микро-акценты) |

**Запрещено как база:** чистые `#FFFFFF` / `#000000`, случайные серые вне палитры.

### Пропорции на экране

| Цвет | Доля |
| --- | --- |
| Snow Ivory | 60–75% |
| Warm Black | 10–20% |
| Olive Graphite | 5–10% |
| Cream Ivory | 5–7% |
| Champagne | 1–3% |

### Текстовые состояния (от Warm Black)

| Состояние | Непрозрачность | Пример |
| --- | --- | --- |
| Основной текст | 100% | `rgba(44, 41, 41, 1)` |
| Вторичный | 68% | `rgba(44, 41, 41, 0.68)` |
| Placeholder / muted | 52% | `rgba(44, 41, 41, 0.52)` |
| Линии / hairline | 14–28% | `rgba(44, 41, 41, 0.14)` … `0.28` |

На тёмном фоне (Warm Black) текст и иконки — Snow Ivory / Cream Ivory с теми же относительными уровнями контраста.

## Типографика

Только два шрифта. Третий шрифт и подмена на Arial / Helvetica / system-ui как основной — запрещены.

### LT Amber Condensed

- **Medium** — заголовки
- **Regular** — короткие акценты, лейблы, навигация
- Регистр: **капс** для коротких подписей и навигации
- Длинный русский текст капсом — **запрещён**

### Pliant

- **Light** — основной текст (body)
- **Regular** — смысловые выделения в тексте
- Регистр: обычный (sentence case)

### Веб-размеры (desktop / mobile)

| Стиль | Desktop | Mobile | Шрифт / особенности |
| --- | --- | --- | --- |
| H1 | 64–88 px | 42–56 px | LT Amber Medium |
| H2 | 40–56 px | 30–40 px | LT Amber Medium |
| H3 | 24–34 px | 20–28 px | LT Amber Medium |
| Label | 12–18 px | 11–16 px | LT Amber Regular, капс, трекинг 4–8% |
| Body large | 20–26 px | 18–22 px | Pliant Light |
| Body | 16–18 px | 15–17 px | Pliant Light |
| Caption | 12–14 px | 11–13 px | Pliant Light |

**Body / Caption:** интерлиньяж 130–150%, трекинг −1…−3%.

Шрифты: локальные файлы, `font-display: swap`. Preload только двух критичных начертаний.

## Композиция и логотип

- Выравнивание по **левому краю**. Центровка — только короткие карточки и CTA.
- Много воздуха: не уплотнять блоки «вплотную».
- Логотип — только утверждённый векторный файл.
- Без прозрачности, теней, градиентов, искажения пропорций.
- Охранное поле минимум **2X** (X — высота знака / модуля логотипа).
- Минимальная ширина логотипа на сайте: **160 px**.

## Digital rules — Do / Don't

### Do

- Держать фон Snow Ivory; тёмные секции — Warm Black целиком, не «серые пятна».
- Кнопки основного действия — Olive Graphite на светлом / Snow Ivory на тёмном.
- Champagne — точечно (underline, мелкий акцент), не заливать им блоки.
- Использовать токены (CSS-переменные / Tailwind theme), не сырые хекс в компонентах.
- Левый край, спокойная сетка, крупные поля между секциями.
- Alt у контентных изображений; декоративным — `alt=""`.

### Don't

- Не использовать чистый белый/чёрный как основу интерфейса.
- Не вводить сторонние цвета, градиенты «для красоты», glow, лиловые/неон-темы.
- Не ставить Champagne крупными плашками или как основной CTA.
- Не писать длинные русские абзацы капсом.
- Не подменять LT Amber / Pliant системными шрифтами.
- Не центрировать длинные тексты и плотные колонки.
- Не растягивать, обрезать с потерей охранного поля или накладывать эффекты на логотип.
- Не копировать визуал и ассеты чужих брендов (в т.ч. RH / rh.com).
